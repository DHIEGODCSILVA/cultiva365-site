# Cultiva365

Site institucional estático, pronto para GitHub Pages.

## Publicação

1. Crie ou conecte este diretório a um repositório GitHub.
2. Envie os arquivos para a branch `main`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/(root)`.
4. Após a publicação, configure `cultiva365.com.br` em **Custom domain** e ajuste o DNS conforme as instruções do GitHub Pages.

Os textos de contato permanecem genéricos porque nenhum canal oficial foi fornecido.
